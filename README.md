## Milosz Busko

Technical recruiter, ten years, mostly software, data and AI engineering roles across the Netherlands and Belgium. I build the tools I recruit with.

Most recruiters buy AI tooling. I write mine: agents that map a market, draft outreach in my own voice, turn an interview transcript into a filed scorecard, and keep the reporting current. One command now does what used to be an hour of admin after every interview. The rule I hold to is that the agent proposes and I decide, because when I measured it, the candidates I picked by hand accepted five points higher than the ones the model picked.

- **[forkast](https://github.com/milosz-arch/forkast)** — a meal-planning progressive web app for a shared household. Alpine, Tailwind, Firebase, a Gemini vision function for reading recipes from photos, no build step. In use by real families, which is why the interesting parts of it are about offline failure and rate limits rather than features.
